## 依赖关系（关键）

```
        ┌────────────────────────┐
        │ 1. 内核机制（agent-loop）│ ← 地基：所有块的基础
        │    core 子系统           │
        └──────┬──────┬──────┬────┘
               │      │      │
     ┌─────────┘      │      └──────────┐
     ▼                ▼                 ▼
2. 多 Agent       8. 自进化        7. mini-dsh
（依赖内核）      （依赖内核+多Agent）（= 重写内核，综合检验）
     ▲
     │
  dynamic-cordis（依赖内核 + Cordis 内核）
```

**依赖结论**：
- **块 1（内核）是地基**——2 / 7 / 8 / dynamic-cordis **都建在它之上**
- **块 2（多 Agent）最大最实用**（subagent 779 行）——但依赖块 1
- **块 7（mini-dsh）= 重写地基**，必须在块 1 之后
- **块 4/5/6（Web UI / 考古 / 测试）较独立**——可穿插，不依赖块 1
