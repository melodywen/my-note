# 04.1 agent preset 与系统提示词——你的 prompt 是怎么拼出来的

> [!info] 版本锚点
> - 源码：`~/ai-work/dsh/deepseek-harness/`（master `0d1f50007f`）；全局包 `dsh 0.1.5-rc.1`
> - 前置：**04 篇（subagent）**、**09 篇（Profile 定制）**、**05 篇（surface）**
> - 写法说明：本系列采用**完整重讲式**；以**读源码 + 讲机制**为主

> [!abstract] 本章是什么 / 该记住什么
> **回答的问题**："我写了个 agent（带自己的 prompt），怎么落地？" + "`complete: false` 到底保留了啥？"
> **读完该记住 5 点**：
> 1. **写一个 `agent preset`** = 一个文件夹（`preset.yml` + `agent.cordis.yml`）
> 2. **系统提示词 = 一堆 section 按 `order` 拼接**——你的 `persona.prefix` 只是**第 2 段**（order 0）
> 3. **`complete: false`（默认）**：你的 prefix 只是"开场白"，**后面还有官方一大堆 section**（框架身份 + 每个工具的用法 + Web 说明…）
> 4. **`complete: true`**：**只留你这一段**（其余全抑制）
> 5. **最终提示词是"日志里的 `system/message` 节点"**，不是"请求字段"

## 这一篇在讲什么

你问两件事：
1. **"我自己写了个 agent（带 prompt），怎么落地？"**
2. **"`complete: false` 到底保留了啥？"**

**答案**：写一个 **`agent preset`**；而 `complete` 控制的是**"系统提示词怎么拼"**——**本质是同一个问题**（你的 prompt 在整个系统提示词里的位置）。

> **一句话**：**系统提示词不是"一段文字"，是"一堆 section 按 order 拼起来的"**——你的 prompt 是**其中一段**。

---

## 一、系统提示词 = 一堆 section 按 `order` 拼接（核心）

**这是理解 `complete` 的前提。**

### 真实的 section 名单（按 order）

### 装配规则

> **出处**：`system-prompt.zh.md:44`（逐字）——*"各段先按 **order 升序**排列，再按名称的 code-unit 顺序排列。"*

### `renderPrompt`（怎么拼）

> **出处**：`system-prompt/src/index.ts:280-285`（逐字）
```ts
export function renderPrompt(assembly: PromptAssembly): string {
  return assembly.sections
    .map(section => section.interpolate === false ? section.text : interpolate(...))
    .filter(text => text.length > 0)     // 空段丢弃
    .join('\n\n')                         // 两段空行连接
}
```

**即**：**每段渲染 → 丢空段 → 用两个空行拼起来。**

## 二、⭐ `complete: false` 保留了啥？（你问的）

**默认 `complete: false`** → **你的 `prefix` 只是"第 2 段"，后面还有官方一大堆**：

| order | section | 保不保留（complete:false） |
|---|---|---|
| -1000 | **框架身份**（HARNESS_IDENTITY） | ✅ 保留 |
| **0** | ⭐ **你的 prefix** | — |
| 500/600 | 计划/团队策略 | ✅ |
| **1000+** | **每个工具的用法说明**（bash/read/write/edit/glob/grep…） | ✅ |
| 2000+ | 网络工具 / 子 agent / MCP | ✅ |
| 10000/10100 | **框架源码位置 / Web 说明** | ✅ |
| 10200 | **你的 suffix** | ✅（若写了） |

**所以 `complete: false` = 你在官方模板上"加了个开头"，官方的一整套 section 都还在。**

### `complete: true` 干了什么（精确）

> **出处**：`system-prompt.zh.md:65-68`（逐字）——*"Treat this contribution as the complete system prompt. **Assembly still runs the cooperative waterfall**（装配仍会跑，解析工具/上下文/变量），**then restores this exact section as the sole prompt section**（然后只留这一段）。**More than one effective complete section makes assembly fails**（多个 complete 会报错）。"*

**翻译**：
- **装配照样跑**（工具/上下文/变量都解析）
- **但最后"只留你这一段"**（`sole prompt section`）
- **只能有一个 `complete`**（多个报错）

**`minimal` preset 就用了它**——**系统提示词只有一句**：
```yaml
- id: persona
  name: '@deepseek-ai/dsh-persona'
  config:
    prefix: You are a helpful software engineer assistant.
    complete: true               # 只有这一句，官方全抑制
    includeRuntimeContext: false
```

> **出处**：`presets/minimal/agent.cordis.yml:7-12`

## 三、`persona` 的 4 个参数

> **出处**：`packages/preset/persona/src/index.ts:30-53`（逐字）

| 参数 | 含义 | 默认 |
|---|---|---|
| **`prefix`** | 渲染为 `deployment:persona-prefix` 段（**你的"人设"写这**） | 必填 |
| `suffix` | 渲染为 `deployment:persona-suffix` 段（在官方指引**之后**） | `''` |
| **`complete`** | **让 prefix 成为"唯一段"**（抑制其他所有 section） | `false` |
| `includeRuntimeContext` | 是否含"运行时上下文快照" | `true` |

**变量**：`{{model}}` / `{{cwd}}`——**自动插值**。

> **出处**：`standard/agent.cordis.yml:23`——*"`{{model}}` and `{{cwd}}` resolve from the agent's own route and workspace."*

### 两种典型写法

**① 加人设（`complete: false`，官方全保留）**：
```yaml
- id: persona
  name: '@deepseek-ai/dsh-persona'
  config:
    prefix: 你是一个专注的代码审查助手，风格严谨。
    suffix: Your working directory is {{cwd}}.
```

**② 完全替换（`complete: true`，只有你的）**：
```yaml
- id: persona
  name: '@deepseek-ai/dsh-persona'
  config:
    prefix: You are a helpful software engineer assistant.
    complete: true
    includeRuntimeContext: false
```

## 四、另一套：运行时上下文（`CONTEXT_ORDERS`）

**除了 section，还有"运行时上下文"**（动态注入，如 sandbox 策略）：

> **出处**：`system-prompt/src/index.ts:165-169`
```ts
const CONTEXT_ORDERS = {
  SANDBOX_POLICY: 110,
  APPROVAL_POLICY: 115,
  SUBAGENT_DELEGATION: 120,
}
```

- **`includeRuntimeContext: false`** → 抑制这些
- **`suppressRuntimeContext()`** → 更狠的抑制（`ctx.systemPrompt` 的方法）

## 五、写在哪个 preset 文件 + 放哪

### 一个 preset = 文件夹 + 2 文件

```
presets/my-agent/
├── preset.yml           ← 元信息
└── agent.cordis.yml     ← agent 定义（persona 在这）
```

**`preset.yml`**（真实）：
> **出处**：`presets/minimal/preset.yml`
```yaml
name: 极简模式
description: 仅提供持久 shell 的单工具编码 Agent。
order: 3
```

### 放哪

| preset | 位置 |
|---|---|
| **内置**（standard/ptc/minimal/cordis） | 包内 `packages/preset/agent-presets/presets/`（`SHIPPED_PRESET_ROOT`） |
| **你自己的** | **`~/.dsh/.agent-presets/<名>/`**（`USER_PRESET_DIR = '.agent-presets'`） |

> **出处**：`discovery.ts:51`（`USER_PRESET_DIR`）、`:60`（`SHIPPED_PRESET_ROOT`）

### 选中

`~/.dsh/settings.yaml` 的 `agent-presets.default`（如 `standard`），或 UI 里切。

## 六、⭐ 最终提示词怎么到模型（回扣 05 篇）

> **出处**：`system-prompt.zh.md:44`（逐字）——*"agent loop 用 `renderPrompt` 渲染组装后的各段，并把文本作为 **`system/message` surface 节点**提交……因此**提示词作为派生历史中的消息而不是请求字段**到达模型。"*

**意思**：**提示词不是"请求的一个字段"，而是"会话日志里的一个 `system/message` 节点"**（surface 第 0 号）。

> **回扣**：这就是 05 篇讲的 surface——**提示词变更是"替换/追加一个系统节点"**（可被 compaction、Fork 影响）。

## 七、动手：写一个自己的 preset（指南）

> **规则（AGENTS.md）**：动手环节"你动手"。本节是**写法指南**（未实测）。

```sh
# ① 建目录
mkdir -p ~/.dsh/.agent-presets/my-reviewer

# ② 元信息
cat > ~/.dsh/.agent-presets/my-reviewer/preset.yml <<'EOF'
name: 代码审查助手
description: 专注代码审查
order: 10
EOF

# ③ agent 定义（你的 prompt 在这）
cat > ~/.dsh/.agent-presets/my-reviewer/agent.cordis.yml <<'EOF'
- id: persona
  name: '@deepseek-ai/dsh-persona'
  config:
    prefix: 你是严谨的代码审查助手，只在被要求时审查，给具体问题 + 建议。
    # 想完全用自己的 prompt？加 complete: true
EOF

# ④ 起 dsh，UI 里选这个 preset
./start.sh
```

> **⚠️ 未实测**：基于源码机制（`USER_PRESET_DIR` / `persona` 参数），**未实跑**——报错一起排查。
> **💡 捷径**：官方 **`cordis` preset**（"创造模式"）**专门用来创建自定义 preset**（含创作指导）——可让它在 UI 里帮你写。

## 踩坑预防

- **⚠️ `complete: false` 不是"没保留"**：它保留**官方一整套 section**（工具说明等）。（出处：`SECTION_ORDERS`）
- **⚠️ `complete: true` 会砍掉官方指引**：适合"我就要我的 prompt"；否则别开。（出处：`persona:43`）
- **⚠️ 多个 `complete` 会报错**：只能一个。（出处：`system-prompt:68`）
- **⚠️ preset 放 `~/.dsh/.agent-presets/`**（不是 `profiles/`）。（出处：`discovery:51`）
- **⚠️ 未实测**：写法指南未实跑。（出处：诚实标注）
