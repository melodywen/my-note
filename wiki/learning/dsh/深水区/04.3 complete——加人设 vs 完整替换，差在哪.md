# 04.3 complete——"加人设" vs "完整替换"，差在哪

> [!info] 版本锚点
> - 源码：`~/ai-work/dsh/deepseek-harness/`（master `0d1f50007f`）；全局包 `dsh 0.1.5-rc.1`
> - 前置：**04.1 篇（系统提示词组装）**——本篇是它的**焦点篇**，专讲 `complete`
> - 写法说明：本系列采用**完整重讲式**；**用真实 section 文本对比**

> [!abstract] 本章是什么 / 该记住什么
> **回答的问题**："`complete: true` 和 `false` 到底差多大？"
> **答案**：**差得"巨大"**——`false`（默认）保留**官方一整套 section**；`true` **全砍**（只剩你的）。
> **读完该记住 3 点**：
> 1. **`complete: false`**：你的 prefix = "开场白"，**框架身份 + 每个工具的用法 + Web 说明全在**
> 2. **`complete: true`**：**只有你这一句**（上面那些全没了）——**模型可能"不会用工具"**
> 3. **绝大多数情况用 `false`**；`true` 只用于**评测/极简/就要自己那套**

## 这一篇在讲什么

04.1 讲了"系统提示词 = section 数组"。这一篇**聚焦一个开关**：**`persona.complete`**——它决定**"官方那一堆 section 保不保留"**。

> **出处**：`persona/src/index.ts:43`（逐字）——*"Make the prefix the complete system prompt, **suppressing the suffix and every other section**."*

**一句话**：
- **`complete: false`（默认）** = **你在官方模板上加"开场白"**
- **`complete: true`** = **你从白纸写**（官方啥都不加）

---

## 一、先看**真实 section 文本**（这是最有说服力的）

**"官方那一堆"到底是啥？** 看几个**真实文本**：

### 框架身份（`HARNESS_IDENTITY`，order −1000）

> **出处**：`system-prompt/src/index.ts:430`（逐字）
```ts
text: 'You are an AI agent powered by DeepSeek Harness.'
```

### 每个工具的用法说明（`TOOL_*`，order 1000+）

**bash**（`tool-bash/src/index.ts:238`，逐字）：
```ts
text: 'Check the [exit code: N] marker on every bash result; investigate failures before moving on.'
```

**read**（`tool-fs/src/read.ts:71-74`，逐字）：
```ts
text: ({ scope }) => ctx.tools.get('read', scope) === undefined
  ? ''
  : 'Use the read tool — not shell commands like cat — to inspect text files. Results include line numbers. Use offset and limit to continue reading large files.'
```

**——每个工具**（bash/read/edit/glob/grep/web/…）**都注册自己的 "用法说明" section**。

### 这就是 `complete: true` 会**砍掉**的东西

> **出处**：`SECTION_ORDERS`（`system-prompt/src/index.ts:125-160`）——`HARNESS_IDENTITY` + 几十个 `TOOL_*` + `WEB_SURFACE` + `HARNESS_SOURCE` + …

---

## 二、`complete: false`（默认）——你的 prefix 只是"开场白"

**写**：
```yaml
- id: persona
  name: '@deepseek-ai/dsh-persona'
  config:
    prefix: 你是一个专注的代码审查助手，风格严谨。
    suffix: Your working directory is {{cwd}}.
```

**模型最终收到的系统提示词**（**示意**，按 order 拼）：

```
你是一个专注的代码审查助手，风格严谨。              ← ⭐ 你的 prefix（order 0）
Your working directory is /xxx.                  ← 你的 suffix

You are an AI agent powered by DeepSeek Harness.  ← 框架身份（order -1000 排最前）

Check the [exit code: N] marker on every bash result…   ← bash 用法
Use the read tool — not shell commands like cat —…      ← read 用法
（edit/glob/grep/web… 各工具用法）
（Web 界面说明、框架源码位置…）
```

**即**：**你的话 + 官方全套**。

**（注：order 排序后，框架身份 −1000 最前，你的 prefix 0 其后——上面只是示意内容，真实顺序以 order 为准。）**

---

## 三、`complete: true`——**只有你的**

**写**（`minimal` preset 的真实用法）：
```yaml
- id: persona
  name: '@deepseek-ai/dsh-persona'
  config:
    prefix: You are a helpful software engineer assistant.
    complete: true
    includeRuntimeContext: false
```

**模型最终收到的系统提示词**：
```
You are a helpful software engineer assistant.      ← 只有这一句
```

**上面那一大堆（框架身份 + 工具用法 + Web 说明）——全没了。**

> **出处**：`system-prompt.zh.md:65-68`（逐字）——*"Assembly still runs… then **restores this exact section as the sole prompt section**."*

---

## 四、⭐ 区别有多大？（实质影响）

| 影响 | `complete: false` | `complete: true` |
|---|---|---|
| 模型知不知道**有 bash 工具、怎么用** | ✅（有用法说明） | ❌ **不知道**（得猜/schema） |
| 模型知不知道**自己在 Web UI** | ✅ | ❌ |
| 模型知不知道**自己是 dsh agent** | ✅ | ❌ |
| 使用体验 | **完整、顺手** | **"冷启动"——只按你说的来** |

**核心风险**：**`complete: true` 砍掉了工具用法说明** → **模型可能"不会用工具"**（尤其工具多时，它不知道"bash 结果要检查 exit code"之类）。

> **⚠️ 严重警告**：**除非你有意为之（评测/极简），否则别开 `complete: true`。**

---

## 五、什么时候用哪个

| 场景 | 用哪个 | 为什么 |
|---|---|---|
| **日常定制 agent**（换人设，保留能力） | ✅ **`complete: false`** | **绝大多数情况** |
| **模型评测**（固定 prompt，排除干扰） | ✅ `complete: true` | 想给"完全固定的输入" |
| **极简实验** | ✅ `complete: true` | `minimal` 的用法 |
| **"官方别插话，就要我这套"** | ✅ `complete: true` | 有意为之 |

**默认建议**：**`complete: false`**（你不写这个字段就是 false）。

---

## 一页纸总结

| 概念 | 含义 | 出处 |
|---|---|---|
| **`complete: false`**（默认） | 你的 prefix = 开场白；**官方全保留** | `persona:43` |
| **`complete: true`** | **只有你这段**（官方全抑制） | `system-prompt:65-68` |
| **框架身份真文本** | `You are an AI agent powered by DeepSeek Harness.` | `system-prompt:430` |
| **bash 用法真文本** | `Check the [exit code: N] marker…` | `tool-bash:238` |
| **read 用法真文本** | `Use the read tool — not shell commands like cat —…` | `tool-fs/read:72` |
| **多个 complete** | 报错（只能一个） | `system-prompt:68` |
| **默认建议** | `false`（绝大多数情况） | 经验 |

## 踩坑预防

- **⚠️ `complete: true` 会砍掉工具用法说明**：模型可能"不会用工具"——**除非有意为之，别开**。（出处：`SECTION_ORDERS` + 真文本）
- **⚠️ 多个 `complete` 报错**：只能一个。（出处：`system-prompt:68`）
- **⚠️ `complete: true` 也砍你的 suffix**：*"suppressing the suffix and every other section"*。（出处：`persona:43`）
- **⚠️ 别把 `complete` 和 `includeRuntimeContext` 混**：前者砍 section，后者砍"运行时上下文"。
