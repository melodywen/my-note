# 10.0 远程调用与多端——本章地图

> [!info] 版本锚点
> - 源码：`~/ai-work/dsh/deepseek-harness/`（master `0d1f50007f`）；全局包 `dsh 0.1.5-rc.1`
> - 前置：**08.1（浏览器/服务器边界）** 强烈建议先读；**09 章（配置即插件树）** 也会回扣
> - 本篇对象：**有分布式/后端经验，想看懂 dsh 怎么"把 Host 能力暴露给各端"的人**

> [!abstract] 这一章讲什么 / 该记住什么
> **回答的问题**："**Host（后端）的能力，怎么变成 Web / Desktop / IDE / 脚本能调用的东西？**"
> **答案**：**两条线**——
> 1. **Typert 协议**：在 Host 方法上打 `@Remote` 标记 → **自动生成 Client 能调用的方法**
> 2. **多端**：Web / Desktop / CLI / SDK / ACP = **同一个 harness + 不同 profile**（不是多套代码）
> **读完该记住 5 点**：
> 1. **Typert 像"自动化版 gRPC"**——不写 proto，直接在 TS 方法上打标记
> 2. **Lookup 是精髓**：复杂 Host 对象（如 `Agent`）过不了 wire，**wire 上只传 id，Gateway 调前解析回来**
> 3. **传输层 = Connection（HTTP/WS 载体）+ Gateway（dispatch）**
> 4. **Web Client 有六层**：Host 状态 → 传输 → Client model → UI adapter → Conversation → Slots/React
> 5. **"多端"不是多套代码**——是"一个 harness，不同 profile/传输"（回扣 09 章"配置即插件树"）

## 为什么这一章对后端特别亲切

**这一章讲的，全是你熟悉的东西**：

| dsh 的概念 | 你的后端经验 |
| --- | --- |
| Host ↔ Client 两个进程 | 服务端 ↔ 客户端 |
| Typert `@Remote` | gRPC / OpenAPI / RPC stub 生成 |
| Lookup（对象 → id） | 序列化：对象不能过网，只能传 id |
| 调用描述符 / 编解码 | protobuf schema / DTO |
| 带外取消 `AbortSignal` | gRPC 的 `context.Context` 取消 |
| Connection / Gateway | 传输层 / 路由层 / API 网关 |
| Client model（状态镜像） | 客户端缓存 / CQRS 读模型 |
| 重连 / generation | 连接池 / 断线重连 |

> **一句话**：**你在后端做过的"服务间调用"，dsh 在"Host↔多端"之间又做了一遍**——只是**多了一层"自动生成"**（Typert）。

## 本章两条线（一张图）

```
                  ┌─────────────────────────────────────────┐
                  │   Host（后端进程：跑 agent / 读写文件）    │
                  │   ctx.goals / ctx.terminals / ...         │
                  └──────────────────┬──────────────────────┘
                                     │  ① 打 @Remote 标记
                                     ▼
        ┌───────────────── 线 A：Typert 协议 ─────────────────┐
        │  构建时：分析 TS 方法 → 生成 descriptor + codec      │
        │  运行时：Gateway 解析对象 → 调真实服务 → 校验返回值   │
        └──────────────────┬──────────────────────────────────┘
                           │  ② 通过 Connection（HTTP/WS）传输
                           ▼
        ┌───────────────── 线 B：多端 ────────────────────────┐
        │  Web（浏览器）   Desktop（Electron）                │
        │  CLI（终端）     SDK（Python/Node 嵌入）            │
        │  ACP（编辑器/IDE，走 Agent Client Protocol）        │
        └─────────────────────────────────────────────────────┘
                           │  ③ Client 端：ctx.remote.<ns>.<method>
                           ▼
                    await ctx.remote.goals.create(...)
```

**线 A（Typert）** 回答"**怎么暴露**"；**线 B（多端）** 回答"**暴露给谁**"。
