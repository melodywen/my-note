## 一个重要的初印象：官方"自进化"的机制早就学过了

**线 B 的核心机制，你在 02 章《dynamic-cordis》里已经见过雏形**：

> **出处**：`packages/extensions/tool-cordis/README.zh.md`（逐字）——*"`dsh-tool-cordis` 让**模型检查实时 Cordis 运行时，并创建、运行、停止、更新或移除包含 host 代码、浏览器代码或两者的临时动态包**。包版本**不可变**，因此包失败后，模型可以**添加新版本并更新当前运行的版本**。"*

**翻译**：**Agent 在运行时，自己写一个插件 → 挂上 → 试 → 不行就改 → 再挂**。**这就是"自进化"的字面意思。**

> **回扣 02 章**：02 讲的是"让 Agent 运行时自己写插件"——**11.3 就是它的"完整形态 + 官方样板"**。
