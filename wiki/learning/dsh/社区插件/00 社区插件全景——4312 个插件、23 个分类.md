> [!abstract] 这篇文章是什么
> **一张"社区插件地图"**——把 dsh 生态里的插件**按类别摊开**：
> 1. **生态有多大**（4312 个）
> 2. **分几类**（23 类，附中文对照）
> 3. **每类有哪些代表作**（带链接，可直接点开）
>
> **⚠️ 这不是"推荐榜"**——按官方清单原话，它**不排名、不评质量**。本文只做"**分类 + 导航**"。

> [!warning] 一个必须澄清的点：这个分类**不是 dsh 官方定的**
> - **dsh 官方**（`deepseek-ai`）**不定义插件分类**——官方只管协议（`dsh.bundle` 怎么声明）。
> - **23 个分类**是**社区清单 `awesome-dsh-plugin` 自己分的**（在它 README 的 `## Contents` 段）。
> - 出处：<https://github.com/awesome-dsh-plugin/awesome-dsh-plugin/blob/main/README.md>
>
> 也就是说：**装/写插件看官方协议；"有哪些分类"看这个社区清单。**

## 一、生态规模：先看数字

> **出处**：官方徽章 <https://awesome-dsh-plugin.com/count.json>（2026-09 抓取，原文）：

```json
{"schemaVersion":1,"label":"plugins","message":"4312","color":"c0392b"}
```

| 数字 | 含义 |
| --- | --- |
| **4312** | `awesome-dsh-plugin` 精选清单收录的插件数 |
| **23** | 该清单的分类数 |
| **16084** | GitHub topic `dsh-plugin` 的仓库数（**含大量蹭标签的**） |

> **⚠️ 两个数字为什么差这么多？（16084 vs 4312）**
> 因为 **GitHub topic 谁都能打**，里面混了大量**只为曝光贴标签**的无关项目。而 `awesome-dsh-plugin` 的 4312 条是**核对过源码、确认能 `dsh plugin add` 安装**的。
>
> **出处**：awesome 清单 README 原文（<https://github.com/awesome-dsh-plugin/awesome-dsh-plugin>）——
> *"An entry is added when the plugin **installs with `dsh plugin add`, does what its one-line description says, sits in the right category, and is maintained.** Every submission is **checked against its own source** before merging."*

> **Go 类比**：**这就是"精选清单 vs GitHub 搜索"的区别**——像 `awesome-go` 的精选 vs 你自己 `github.com/search` 搜出来的一堆。**精选的价值就是"过滤"。**

## 三、先装一个"插件市场"（最实用的一步）

**别一个个手动搜**——先装**插件市场**，在 dsh 界面里点着装：

> **出处**：`dsh-market` —— <https://github.com/dsh-market/dsh-market>（awesome 清单推荐的官方市场）

```sh
dsh plugin --profile web add dshmarket
```

> **⚠️ 安全提醒**（出处：awesome 清单 README 的 WARNING 段，<https://github.com/awesome-dsh-plugin/awesome-dsh-plugin#disclaimer>）——
> *"Installing a plugin **runs third-party code on your machine with your own permissions** — it can read your files, use your credentials, and reach the network. **Tool approvals don't sandbox plugin code.** Being on this list is **not a security review**: check the source before you install."*
>
> **翻译**：**装插件 = 运行别人的代码（有你的权限）**——能读你文件、用你凭据、联网。**上清单 ≠ 安全审核**，装前先看源码。

> **Go 类比**：**跟你 `go get` 一个第三方库一样**——能用，但得知道它谁写的。**dsh 更重，因为插件能碰你的文件系统。**

### 🔒 安全与权限（Security & Permissions, 149）

- [`dsh-ui-auth`](https://github.com/0QwQ0/dsh-ui-auth) — Web UI 认证网关（覆盖页面/API）

> **回扣 11.1**：这类"留证据"的设计，正是 postmortem 文化的延伸。

### 📱 远程与移动（Remote & Mobile, 132）

- [`dsh-pocket`](https://github.com/shaobeichen/dsh-pocket) — 电脑跑 `dsh web`，手机扫码同步访问（局域网+公网）
- [`chicheng-gate`](https://github.com/534119219/chicheng-gate) — 局域网/远程 + frpc 内网穿透 + 移动 UI 适配
- [`dsh-mobile`](https://github.com/Clarklevis1995/dsh-mobile) — 移动端

> **回扣**："手机操作"——社区已有现成方案（`dsh-pocket` 就是干这个的）。

### 🎨 主题与外观（Themes & Appearance, 150）+ 🤪 纯好玩（Just for Fun, 128）

- [`dsh-neo-skin`](https://github.com/0nt-one/dsh-neo-skin) — 新粗野主义皮肤
- [`dsh-pet-live2d`](https://github.com/A8Chann/dsh-pet-live2d) — Live2D 桌面宠物
- [`dsh-think-bounce-pet`](https://github.com/9livewolf/dsh-think-bounce-pet) — 两只深寻在界面上弹来弹去（**没实际用途**）

> **回扣**：有闲人做没用的东西，说明**生态活着**。

### 🏗️ AGI 架构探索（AGI Architecture Exploration, 15）——最值得读源码的

- [`dsh-answer-reviewer`](https://github.com/bycall/dsh-answer-reviewer) — **每轮回答由独立模型复评（1-100 分）**，低于阈值把 agent 拉回重做
- [`dsh-quality-review`](https://github.com/CAI-MH/dsh-quality-review) — 独立审阅模型审计每轮输出（最多 2 轮修正）
- [`dsh-gungnir`](https://github.com/Jonah-Wu23/dsh-gungnir) — **证据驱动的目标验证**：用命令退出码 + 产物验证，防模型虚报
- [`dsh-heartbeat`](https://github.com/Kanadego/dsh-heartbeat) — 心跳循环：每 20 分钟自己醒来研究你的兴趣、发消息给你

> **回扣 11.4**：这 15 个就是"**自进化闭环**"在社区的真实实践——`dsh-answer-reviewer`（**评测**）、`dsh-gungnir`（**验证**）、`dsh-heartbeat`（**主动/异常驱动**）。

```bash

# → {"schemaVersion":1,"label":"plugins","message":"4312","color":"c0392b"}

curl -sL "https://raw.githubusercontent.com/awesome-dsh-plugin/awesome-dsh-plugin/main/README.md"

# ③ 只看分类名（验证"分类在 README 里"）
curl -sL "https://raw.githubusercontent.com/awesome-dsh-plugin/awesome-dsh-plugin/main/README.md" | grep "^### "

# ④ GitHub topic 搜索（按 stars）
curl -s "https://api.github.com/search/repositories?q=topic:dsh-plugin&sort=stars&order=desc&per_page=100"
```
