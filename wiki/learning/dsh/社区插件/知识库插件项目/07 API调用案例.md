## 一、这是什么

第三方 API / client 的**调用范例库**——独立知识库。会话中遇到（自己写的或见到的）好用法就收集，**后续再用到同一 SDK/API 时直接参考集成**。

## 二、内容 schema（待议）

一条案例的字段草案：

```yaml
---
title: <场景名，如「分页遍历的正确姿势」>
sdk: github.com/redis/go-redis/v9     # SDK / API 名
version: v9.5.1                        # 验证过的版本
source: <代码来源>                     # 自己写的项目 / 见到的 repo
collected: 2026-09-27
tags: [pagination, redis]
---
## 代码

## 适用场景

## 坑（版本陷阱、超时语义、连接泄漏…）
```
